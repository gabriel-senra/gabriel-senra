# Gabriel Senra

I'm studying computer science at Providence College, with an expected graduation in May 2029. I'm also a pianist and enjoy building tools that make music creation and enjoyment more intuitive and fun.

## Personal projects

- [Tape](https://github.com/gabriel-senra/tape-showcase): a four-track recorder prototype for macOS, built with C++ and JUCE. Record an idea, layer more parts and return to earlier versions of a session.
- [Chord Synthesizer](https://github.com/gabriel-senra/chord-synthesizer-showcase): an ESP32 instrument that plays seventh and ninth chords from physical buttons, with controls for octave, sound and volume.
- [Chord Chart Generator MCP](https://github.com/gabriel-senra/chord-chart-generator-showcase): a TypeScript server that generates piano, guitar and ukulele diagrams and staff notation for assistant conversations.
- [Code examples](https://github.com/gabriel-senra/engineering-examples): standalone C++ and TypeScript components for queues, parameter smoothing, buttons and keyboard diagrams.

**Languages:** C++, Python, TypeScript. **Tools:** JUCE, ESP32, AMY, CMake, Git.
